Baltic Imbalance Regime Forecast

Six-hour ahead (24 × 15-minute) probability forecast of Baltic imbalance regimes — NEG (grid deficit), ZRO (balanced), POS (grid surplus) — and expected imbalance prices. The model (regime_v6_light_top100) lives in a separate private repository and runs on demand via GitHub Actions. Last forecast: —.

Forecast control

The latest forecast (read-only) loads automatically when you open the page. To request a fresh run, enter the shared password and activate — that triggers a workflow dispatch immediately and then again every 15 minutes until you deactivate. Each cycle: dispatch → poll for completion → refetch forecast.json → redraw the charts.

—

Private GitHub repository hosting the model and forecast.json. Edit the constants at the top of forecast-app.js to point at your repo.

The password gates workflow dispatches server-side. It is never persisted to disk, browser storage or URL — only held in memory while the page is active. Deactivate or reload to clear it.

idle

Activation state and last-dispatch result. Wrong password → the workflow exits in ~5 s and shows "auth failed"; the displayed forecast stays at the last successful read.

Probability per horizon

Stacked bar per horizon (15-minute step). NEG = grid deficit (system needs upward energy), ZRO = balanced, POS = grid surplus (system needs downward energy). Heights sum to 1.

Expected imbalance price

Per-horizon model-weighted expected price (solid line) plus the calendar-only baseline (dashed) for reference. The gap between them is the value the model adds beyond what a no-model expectation gives.

Per-horizon detail

Full numeric forecast for every horizon. Sortable by clicking a header (delivery time / argmax / expected price).
