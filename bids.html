Baltic Balancing-Energy Bids — mFRR

Live individual mFRR balancing-energy bids for the three Baltic scheduling areas — Estonia, Latvia, Lithuania (ENTSO-E GL EB 12.3.B&C), pulled on demand via GitHub Actions. Pick an area below to see eight histograms — the offered MW by price bin for the four most recent 15-minute delivery periods (UTC), split into mFRR up and mFRR down. Bid data control

Enter the shared password and click Run bids pull to dispatch a single bids.yml run. The page polls for completion (up to 15 minutes; a bids pull is typically ~1–2 min), refetches bids.json and redraws the eight histograms. It runs exactly once per click — click again for a fresher pull. While a run is in flight the button becomes Cancel.

The same shared password used by the Forecast page. It gates workflow dispatches server-side and is never persisted to disk, browser storage or URL — it stays only in the masked field and in memory during a run. Reload to clear it.

Scheduling area

mFRR up — offered MW by price

Upward balancing-energy bids (the price/volume the market offered to increase supply). One histogram per delivery period, oldest to newest. X = bid price (€/MWh, binned); Y = total MW offered in each price bin. The four panels share price and MW scales so you can see the bid stack shift period-to-period.

mFRR down — offered MW by price

Downward balancing-energy bids (the price/volume the market offered to decrease supply; prices are frequently negative). Same layout as above — one histogram per delivery period, shared scales across the four panels.

Bid data and runner code live in a separate private repository; this page only reads bids.json and triggers workflow runs. Source: classic ENTSO-E REST API (documentType A37, businessType B74).
